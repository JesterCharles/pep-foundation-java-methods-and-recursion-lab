# Methods and Recursion — Code lab

Build a text-analysis utility for a note-taking app: word counts, shortened headlines and mirrored ends, using methods, overloading, static members, two-pointer loops and recursion.

- **Edit:** `src/main/java/exercise/TextScan.java`. Each task is marked `TODO`.
- **Run the tests:** **Run Tests** in Exa Studio, or `mvn test` with JDK 17 and Maven. All 7 visible tests fail at first; every message starts with `Task N:`.
- **Done** when every visible test passes. **Submit** also runs held-out tests you can't see.

Full task steps and hints: [`.evolv/instructions.md`](.evolv/instructions.md)
